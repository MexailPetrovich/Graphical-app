Описание
GUI-приложение для хранения информации о фильмах.  
Позволяет:
- Добавлять фильмы с названием, жанром, годом и рейтингом
- Фильтровать по жанру и году
- Сохранять/загружать данные в JSON
- Проверять корректность ввода (год — число, рейтинг 0–10)

Пример использования

1. Запустите `movie_library.py`
2. Введите:
   - Название: `Побег из Шоушенка`
   - Жанр: `Драма`
   - Год: `1994`
   - Рейтинг: `9.7`
3. Нажмите `Добавить фильм`
4. Для фильтрации введите `Драма` в поле "Фильтр по жанру" и нажмите `Применить фильтр`

Тесты (примеры)
- Попробуйте добавить фильм с годом `abcd` — программа покажет ошибку
- Рейтинг `15` — ошибка
- Фильтр по году `1994` — покажет только фильмы этого года

Файлы
- `movie_library.py` — основной код
- `movies.json` — база фильмов (создаётся автоматически)

Требования
- Python 3.6+
- Стандартные библиотеки: `tkinter`, `json`, `os`
